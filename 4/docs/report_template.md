# Week 5 随堂 Vibe 实验报告模板

## 一、实验名称

词义消歧与语义角色标注系统设计与实现

## 二、实验目的

本实验围绕自然语言处理中的两个典型语义分析任务展开：词义消歧（Word Sense Disambiguation, WSD）和语义角色标注（Semantic Role Labeling, SRL）。实验目标是基于 Python 和 Streamlit 搭建一个交互式 Web 平台，对比传统方法与深度学习方法在语义分析中的表现，并通过实际运行结果加深对课堂理论的理解。

## 三、实验环境

- 开发语言：Python
- Web 框架：Streamlit
- 主要库：nltk、spaCy、transformers、torch、pandas、scikit-learn
- 开发工具与 LLM：可填写自己实际使用的工具，例如 Codex GPT-5.4

## 四、理论基础

### 4.1 词义消歧（WSD）

根据课件内容，词义消歧的任务是根据词语所处的上下文，为多义词选择最合适的词义。课件 P5 说明了 WSD 的基本流程，包括候选词义提取、上下文分析与消歧决策。

本实验主要实现了两类方法：

1. 基于词义释义匹配的方法  
   课件 P18 介绍了基于词汇知识资源的消歧思路。该方法利用 WordNet 等知识库中提供的词义释义信息，根据上下文与释义的匹配程度来选择词义。本实验使用 `nltk.wsd.lesk` 实现这一传统方法。

2. 基于上下文向量表示的方法  
   课件 P10 说明了深度学习方法通过上下文向量表示目标词语义的思路。课件 P21 进一步介绍了基于 BERT 的上下文编码方式，即取目标词所在位置的输出表示作为目标词的上下文表示。本实验采用 `bert-base-uncased` 提取目标词在不同句子中的上下文向量，并通过余弦相似度比较两个语境下词义表示的差异。

### 4.2 语义角色标注（SRL）

课件 P43 指出，语义角色标注是一种浅层语义分析技术，其核心目标是分析句子的谓词-论元结构，揭示“谁在什么时间和地点对谁做了什么”。

在该理论框架下：

- 谓词（Predicate）表示句中的核心动作或事件
- 论元（Argument）表示与谓词相关的参与者或成分
- 常见角色包括：
  - `A0`：施事者（Agent）
  - `A1`：受事者（Patient）
  - `AM-LOC`：地点修饰语
  - `AM-TMP`：时间修饰语

课件 P49 说明，谓词和论元之间的关系可以通过依存关系树进行刻画。因此，本实验基于 spaCy 的依存句法分析结果，使用启发式规则对 SRL 进行轻量级近似实现。

## 五、系统设计

### 5.1 总体结构

本系统基于 Streamlit 实现，包含两个标签页：

- 标签页 1：WSD 词义消歧对比测试
- 标签页 2：SRL 语义角色标注提取与可视化

### 5.2 WSD 模块设计

输入内容包括：

- 第一个包含多义词的英文句子
- 目标词
- 第二个包含同一目标词的英文句子

输出内容包括：

- Lesk 算法预测的 WordNet Synset
- 对应的英文 Definition
- 两个句子中目标词的 BERT 上下文向量余弦相似度

设计思路如下：

1. 使用 `nltk.word_tokenize` 对句子进行分词
2. 调用 `lesk` 对目标词进行词义预测
3. 加载 `bert-base-uncased`
4. 提取目标词在句中的上下文向量
5. 对两个句子的目标词向量计算余弦相似度

### 5.3 SRL 模块设计

输入内容为一个英文句子，系统默认示例为：

`Apple is manufacturing new smartphones in China this year.`

输出内容包括：

- 结构化语义角色表格
- 依存关系图

启发式规则如下：

- 将主要动词（`ROOT` 或 `VERB`）视为谓词
- 将 `nsubj` 映射为 `A0`
- 将 `dobj` 或 `obj` 映射为 `A1`
- 将时间相关短语映射为 `AM-TMP`
- 将地点相关短语映射为 `AM-LOC`

分析：

## 七、实验结论

本实验完成了一个包含 WSD 和 SRL 两个模块的交互式 Web 系统，并通过实际运行验证了课堂中的关键理论。

- 在 WSD 任务中，传统方法和深度学习方法体现出不同特点。Lesk 方法可解释性较强，但依赖词典与上下文词汇匹配；BERT 方法能够体现动态上下文语义表示，更适合区分复杂语境中的词义。
- 在 SRL 任务中，虽然本实验未使用完整的端到端 SRL 模型，但依托依存句法分析和启发式规则，仍可较好地展示谓词-论元结构的基本思想。

## 八、不足与改进方向

- 当前 WSD 的 BERT 实现主要用于上下文表示对比，并未直接完成监督式词义分类。
- 当前 SRL 采用的是基于依存关系的启发式近似方法，对被动句、复杂从句和多谓词句子的处理能力有限。
- 后续可尝试引入更完整的 SRL 数据集或预训练模型，如结合 PropBank 或 CoNLL 风格资源进一步提升系统效果。
